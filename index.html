Human review queue

Selection routes a project to the pre-project authorization gate; it does not start work. Submission completeness is checked with simple rules. Scientific merit is not decided automatically.

Pre-project authorization

Scientific selection does not authorize work to start. Confirm applicable institutional approvals, IP/open-source rights, project scope, in-kind resource allocation, and authorized program sign-off. These are proposed internal controls, not a claim that Snorkel requires a separate agreement or SLA for every project.

Agreements & execution

Internal approval, signature/execution, and verification are separate events. A separate contract is only required when applicable. This demo records attestations and uploaded evidence; it does not create legally verified electronic signatures.
